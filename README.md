# Rosema

Учебный мессенджер. Практика ПМ.02, группа ИСП-43.
Кононов К.А., Артюхин А.Н.

## Модули (дни 4–10)

Каркас и логика без интерфейса:

- `src/` — storage, events, session, contacts, profile, messages, reactions
- `tests/` — unit и интеграционные тесты
- `docs/` — стандарты, дневники, схемы, протоколы

```bash
npm test
```

## Веб-версия

Клиент в папке `web/`: чаты, группы, реакции, голос, кружки, темы, правки сообщений.

```bash
cd web
npm install
npm run dev
```

Откроется локальный сервер Vite. Данные хранятся в браузере (localStorage), без сервера.

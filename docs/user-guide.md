# Руководство пользователя

## Дата: 06.10.2026

Rosema открывается в браузере после запуска веб-версии. Переписка хранится в этом браузере.

## Вход
Учётная запись создаётся на экране регистрации. Имя: с буквы, 4–20 символов, латиница, цифры и подчёркивание. Пароль: 8–20 символов, буква и цифра.

## Переписка
Слева список чатов. Справа сообщения. Пустой текст не отправляется. На сообщение можно поставить реакцию.

## Если что-то пропало
Очистка данных сайта стирает переписку: сервера нет, восстановить неоткуда.

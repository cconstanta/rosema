## Чаты
Слева рейка разделов: все, личные, группы, новые, архив, контакты. Список тянется за правый край. В узком окне остаётся либо список, либо открытый чат. Назад — стрелка в шапке.

Правый щелчок по чату открывает меню: закрепить, без звука, архив, непрочитанное, очистить, удалить. Левый щелчок меню не открывает. Меню браузера поверх строки не нужно.

## Переписка
Текст пишется внизу. Пустое сообщение не отправляется. Правый щелчок по сообщению: ответить, копировать, в избранное, переслать, закрепить, выбрать, изменить своё, удалить своё. Пересланное изменить нельзя. Чужие люди сами ничего не дописывают. Бот отвечает только в своём чате и в основном на команды /help, /time, /dice, /id.

## Профиль
Аватар на рейке открывает профиль. Там тема, свой цвет и обои: котята, море, ночь, цветы.

## Контакты
Раздел «Контакты»: добавить по имени входа или выбрать человека из списка. Нажатие на имя открывает личный чат.

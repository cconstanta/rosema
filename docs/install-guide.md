# Руководство по установке

## Дата: 06.10.2026

Нужны Node.js и git. Папка проекта — корень репозитория.

## Проверка ядра

```bash
npm test
```

Ожидается 13 прошедших тестов.

## Экран

```bash
cd web
npm install
npm run dev
```

Адрес покажет Vite, обычно http://127.0.0.1:5173/. Интернет после установки пакетов для самой переписки не нужен.

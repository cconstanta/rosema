# Баг-репорты

## BR-01. Меню чата закрывается сразу
- **Шаги:** правый щелчок по строке чата.
- **Факт:** меню открывалось и тут же закрывалось.
- **Причина:** запасной щелчок срабатывал и на правую кнопку, срабатывал обработчик открытия чата и сбрасывал меню.
- **Статус:** исправлено. Запасной щелчок только для левой кнопки.

## BR-02. Пустое сообщение
- **Шаги:** отправить пробелы.
- **Факт:** уходить не должно.
- **Статус:** исправлено. checkOutgoing отклоняет пустой текст, есть тест.

## BR-03. Люди отвечают сами
- **Шаги:** написать Артюхину или в группу.
- **Факт:** приходил автоматический ответ.
- **Статус:** исправлено. Автоответ оставлен только боту.
